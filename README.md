## 🚀 How It Works

1. Pick a template
2. Type the recipient name, reason and date
3. Customize colors — download a print-ready PNG

Everything runs **in your browser** — nothing is uploaded, no account needed.

## 💰 Pricing

- **Free**: your first certificate, free to try (small watermark)
- **$9.99 one-time**: all premium templates + watermark-free downloads + unlimited certificates — no subscription

## 🛠 Tech

100% static HTML + vanilla Canvas. No server, no signup, no tracking. GitHub Pages hosting + Cloudflare Worker for license unlock.
