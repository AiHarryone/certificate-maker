What a Good Blank Has

  • Leave the name blank — for handwritten fills.
  • Keep a clean layout — a blank design should still look finished.
  • Add a signature line — usable by any signer.
  • Print as many as you need — the same design, filled differently every time.

How to Use It

  • Print a stack before the event — fill names in pen on the spot.
  • Or type and regenerate — each takes ~30 seconds.
  • Card stock — a blank you fill by hand still deserves good paper.
